Vectors

Search by meaning, not by words

A vector

A list of numbers that describes a piece of text. Stored in a VECTOR column.

An embedding model

Turns text into that list. Real models make hundreds of numbers.

A search

VECTOR_DISTANCE, then ORDER BY and FETCH FIRST. You already know this part.

Today’s demo uses hand-made vectors with 3 numbers: [motor, life, branch].

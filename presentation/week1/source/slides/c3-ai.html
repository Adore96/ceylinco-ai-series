One AI call from SQL

Classify a call transcript

Label each call POLICY, CLAIM, PRODUCT_BRANCH or OTHER.

select json_value( apex_ai.generate(
         p_prompt => 'Label this call POLICY, CLAIM, PRODUCT_BRANCH or OTHER. '
                   || 'Reply with only JSON like {"intent":"POLICY"}. '
                   || q'[ ...the transcript... ]',
         p_service_static_id => 'claude' ), '$.intent' ) as intent
  from dual;

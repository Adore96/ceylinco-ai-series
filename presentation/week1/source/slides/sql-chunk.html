One call returns the chunks as rows

select jt.chunk_id, jt.chunk_length, jt.chunk_data
  from doc d,
       table( dbms_vector_chain.utl_to_chunks( d.body,
         json('{ "by": "words", "max": "40",
                "overlap": "4", "split": "sentence" }') ) ) c,
       json_table( c.column_value, '$' columns ( ... ) ) jt
 order by jt.chunk_id;

Each chunk comes back as JSON. JSON_TABLE turns it into columns.

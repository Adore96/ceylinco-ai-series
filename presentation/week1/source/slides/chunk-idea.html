Chunking

Cut the document before you search it

Why

A search should return one focused paragraph, not a whole manual.

How

DBMS_VECTOR_CHAIN.UTL_TO_CHUNKS cuts text inside the database. One SQL call. No Python.

Settings

Size, overlap, and where to split, for example at sentence ends.

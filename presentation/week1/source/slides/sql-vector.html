Meaning search is an ORDER BY

-- questions: 6 rows, each with a hand-made vector
-- search: "accident repair" as [0.85, 0.05, 0.10]
select round( vector_distance( q.v, s.v, cosine ), 4 )
        as distance,
       q.question
  from questions q
 cross join search s
 order by distance;

Smaller distance means closer meaning. Cosine compares direction, not size.

APEX is SQL with a screen

A report page is a query

-- Source of a report region
select policy_no, product_name,
       status, end_date
  from policies
 where customer_id = :P10_CUSTOMER_ID
 order by end_date

You write the query.

APEX adds the screen: paging, search, sort, filters, download.

:P10_CUSTOMER_ID is a page item, used as a bind variable.
